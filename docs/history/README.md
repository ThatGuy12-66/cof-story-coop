They describe the state at the time they were written; `AGENT_NOTES.md` in the repository root is
the current status, and newer facts there take precedence.

replaced by "the remote friend", and local paths and file names were made generic (for example
`state/enhanced-remote-session.json`, `evidence/remote-…`). Some evidence folders named here
therefore do not exist under these names on the original machine.
