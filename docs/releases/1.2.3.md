cry of fear story co-op 1.2.3 is out

**1.2.3**
- fixed getting stuck in a door's black room. going back through some doors, like c_city back to the bus station map, could leave both players stuck in the dark with no way out. the only way out was changing levels, which just sent you back and forth between maps. the way out was getting carried to the other map the first time you went through and never came back. now each room keeps its way out, rooms that already lost it get it back when the map loads, and arriving in a black room takes you straight through like in single player
- fixed controllers using half-life's layout instead of cry of fear's. sprint, left trigger and stick click, did nothing, and back paused the game. keys still on those half-life binds move to the cry of fear layout the first time you start 1.2.3. any key you set yourself stays the way you set it
- 1.1 to 1.2.3 can all play together. the black room fix is in the host's game and the controller fix is in each player's, so everyone should update

**updating**
- on 1.1.2 or newer, open the app and click Update now
- on 1.1.1 or older, extract the new zip, run CoF Story Co-op.exe and click Update
- saves and settings are kept
