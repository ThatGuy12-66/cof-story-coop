fix for the sky and walls showing the wrong textures on some graphics cards

**1.1.3**
- fixes wrong textures on some cards (reported on an AMD RX 5500): the sky showing walls, or a grey wall stuck in front of u. on those cards the game and the renderer were giving textures the same numbers so one overwrote the other. couldn't test it on that card myself so lmk in bug-reports if it still happens
- 1.1, 1.1.1, 1.1.2 and 1.1.3 can all play together. this fix is in each player's own game, so whoever had the problem should update

**updating**
- on 1.1.2 the app offers it when u open it, just click Update now
- on 1.1.1 or older: extract the new zip, run CoF Story Co-op.exe and click Update. saves and settings are kept
