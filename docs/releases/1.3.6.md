- it starts the exact same game the app's buttons do, same options, same checkpoints
- Join co-op in the game takes the join code too, not just an address, and a password
- while the game's open the app still shows your join code and opens the router port, and the game's Host co-op page shows the code too
- the app's own buttons all still work like before
- 1.1 to 1.3.6 all play together

**updating**
